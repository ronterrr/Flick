## How To Run
To run this website locally:
1. `git clone` this repository
2. Navigate to the `/Flick/flick`
3. Run `npm install` to install the necessary packages and dependencies
4. Run `npm run dev` to launch the project
5. Go to your localhost port (Default: localhost:5173)
6. Enjoy
